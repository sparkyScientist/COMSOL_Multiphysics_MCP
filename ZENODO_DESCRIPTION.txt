COMSOL Multiphysics MCP Server: Physics-Aware MCP Tooling for COMSOL via Java API

This software provides the first Model Context Protocol (MCP) server for
COMSOL Multiphysics, enabling large language models and other MCP clients to
drive COMSOL programmatically through its Java API. The server exposes
physics-aware tools for mesh generation, solver configuration, parametric
sweeps, and results extraction without requiring GUI interaction.

The project builds on wjc9011/COMSOL_Multiphysics_MCP (MIT License), which
established the foundational MCP-to-COMSOL bridge. This work adds several
novel contributions: (1) a physics-aware mesh builder that detects boundaries
via getVertexCoord() and getAdj(1,0), applies injector refinement, boundary
layers, and quality reporting without hardcoded geometry tags; (2) analytic gas
property expressions that bypass COMSOL's GUI-only Thermodynamics package,
providing density (ideal gas law), viscosity (Wilke mixing rule, 3.5% max
error), thermal conductivity (Mason-Saxena blend, 2.4% max error), and heat
capacity (NASA polynomial fits, 0.12% max error) through 51 COMSOL variable
expressions; (3) a segregated solver setup with 4-step physics-aware grouping
covering radiosity, nonisothermal flow, turbulence, and wall functions; (4) a
workflow memory system that stores successful solver configurations for reuse;
(5) an automated 2D-to-3D geometry converter that promotes axisymmetric models
to full 3D; (6) a validator and autofixer that detects and repairs common model
errors post-conversion; and (7) an ARES-Sim bridge that connects multi-objective
Bayesian optimization output to COMSOL CFD validation via gRPC.

The software was developed and validated on 2D and 3D floating catalyst chemical
vapor deposition (FCCVD) carbon nanotube reactor models. Validation covers
vertical downflow (SHELLY) and horizontal (TED) reactor geometries with
nonisothermal flow, k-epsilon turbulence, surface-to-surface radiation, and
multi-component He/N2/CH4/H2 gas mixtures at temperatures from 300 K to 1400 K.

This tool is intended for COMSOL Multiphysics users who want to automate
simulation workflows, researchers building AI-driven simulation pipelines, and
MCP tool developers working with physics simulation backends. It requires
COMSOL 6.3 or later, Python 3.12, and the MPh library (v1.3.1) for Java API
access.
